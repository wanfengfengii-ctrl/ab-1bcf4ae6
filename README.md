# 帆船主帆修补 · 排版工作台

帆装师在浏览器中录入帆布、补片与裁切候选，点击「排版」后由本机求解器为每块补片联合选择一个候选，避免局部最省料的选法让其他补片无处可裁。

## 快速开始

```bash
# 启动 Web（宿主机端口默认 8080，可用 WEB_PORT 覆盖）
docker compose up --build web
WEB_PORT=9000 docker compose up web   # http://localhost:9000

# 一次性校验：代码测试 + 构建 + 候选冲突业务冒烟，以退出码报告结果
docker compose up --build --exit-code-from verify verify
echo $?   # 0 = 全部通过
```

`verify` 服务依次执行：字节码编译（构建）、pytest（代码测试）、对 `web` 服务的
HTTP 业务冒烟（候选冲突→无解、首块无兼容候选、联合择优目标值、草稿修改→旧结论失效），
完成后自行退出，退出码 0 表示全部通过、1 表示存在失败项。

## 领域规则与口径

- **帆布**（2–3 张）：宽、高、经纬方向（经向沿宽 / 沿高）、边缘禁裁宽度（四边统一扣除）。
- **补片**（3–5 块）：纤维方向要求（经向沿补片宽 / 高）。
- **候选**（每块补片 2–4 个）：所属帆布、左上整数坐标、宽、高、旋转（0°/90°）。
  宽×高即布上占地；旋转 90° 只使纤维方向互换，不改变占地。
- **兼容条件**：纤维方向相符（布向 ⊕ 旋转 = 补片要求）、完整落在可裁区域内
  （含边缘禁裁）、与同布其他采用裁片无正面积重叠（边缘相接允许）。
- **联合择优**（字典序）：
  1. 使用帆布张数最少；
  2. 各已用帆布剩余面积（可裁面积 − 已裁面积）的最大值最小；
  3. 按补片录入顺序展开的候选序号（每块补片内从 1 起）字典序最小。
- **无解**：若某块补片没有任何个体兼容的候选，按录入顺序指出首块这样的补片；
  否则说明所有组合均存在正面积重叠，并列出候选冲突对。
- **结论失效**：任何草稿修改（增删帆布/补片/候选）都会使旧排版结论失效，
  前端提示并隐藏旧结论，需重新点击「排版」。

## 结果呈现

- 帆布示意：禁裁带（红底）、可裁区（白底虚线框）、采用裁片（绿色，标注补片序号）、
  个体兼容但未采用的候选（灰色虚线，悬停可见说明）。
- 明细：采用表（补片 → 候选 → 帆布 → 坐标/尺寸/旋转）与排除表（每条未采用候选的理由：
  纤维方向不符 / 超出可裁区域 / 与采用裁片正面积重叠 / 未被最优方案选中）。

## 结构

```
app/solver.py            纯函数联合求解器（枚举 ≤4^5 组合，字典序择优）
app/server.py            Flask API + 静态页（内存草稿 + 修订号失效机制）
app/static/index.html    单页工作台（录入、排版、示意与明细）
tests/                   pytest：求解器规则与 API 行为
verify.py                一次性校验服务（构建 + 测试 + 业务冒烟，退出码报告）
Dockerfile / docker-compose.yml
```

## API 摘要

- `GET /health` 健康检查
- `GET /api/state` 草稿与（未失效的）排版结论
- `POST/DELETE /api/cloths`、`/api/patches`、`/api/patches/{id}/candidates`、`/api/candidates/{id}`
- `POST /api/layout` 联合排版
- `POST /api/reset` 清空草稿
